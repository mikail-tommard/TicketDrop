# TicketDrop

TicketDrop — учебный сервер на Go для продажи билетов на концерт с ограниченным количеством мест. Покупатель бронирует место на две минуты. Если он подтверждает бронь до истечения срока, сервис выдаёт билет. Если срок истекает, место возвращается в продажу. При нескольких одновременных заявках последнее место может получить только один покупатель.

## Что уже работает

HTTP-сервер на стандартном `net/http` слушает порт `8080`. Маршрут `GET /livez` показывает, что процесс отвечает на HTTP-запросы. Бронирование и выдача билетов ещё в разработке.

## Локальный запуск

Понадобится Go 1.26.5 или новее. Из корня проекта запусти сервер:

```sh
go run ./cmd/api
```

В другом терминале проверь маршрут:

```sh
curl -i http://localhost:8080/livez
```

Ожидаемый ответ — `200 OK` с JSON-строкой `"Server is live"`.

## Как устроен проект

- `cmd/api/` — точка входа и настройки HTTP-сервера.
- `internal/adapters/httpapi/` — маршруты, обработчики и запись JSON-ответов.
- `site/` — статический трекер практикума. Его можно открыть через `site/index.html`.

В планируемой архитектуре PostgreSQL хранит остаток мест, брони и билеты. Redis кэширует карточку концерта. Подтверждение брони сохраняет событие в PostgreSQL, а фоновый процесс доставляет его через Kafka для выдачи билета. Prometheus и Grafana показывают нагрузку на API и задержку выдачи.
